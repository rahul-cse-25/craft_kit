# Screenshots

Images and GIFs used by the main README. This folder is kept in the repository
and left out of the published package (see `.pubignore`), so the package stays
small. The README links to these files on GitHub.

Add these files (keep the names, or change the links in `README.md`):

| File | Shows |
|---|---|
| `swipe_overview.gif` | Dragging cards in all four directions with the drag overlay |
| `swipe_genie.gif` | A card pouring into a button (the genie), and undoing it |
| `swipe_undo_rewind.gif` | Undo, and "rewind all" |
| `swipe_overlay.png` | The badge and colour overlay at the commit point |
| `otp.gif` | The OTP field: typing, processing, success and failure |
| `email.gif` | Remembered-email suggestions |

Keep each GIF under about 3 MB and roughly 360 px wide so the README loads fast.
